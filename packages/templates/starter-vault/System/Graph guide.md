# Graph guide

[[Home|Home]]

Recommended Obsidian Graph View settings to maintain a clean, readable knowledge network:

### Graph Filters (Knowledge View)
- Filter query: `-path:Work/Sessions -path:Work/Tasks -path:Templates -path:System`
- Hide operational logs so high-level project and knowledge relationships stand out.

### Recommended Color Groups
- **Me** (`path:Me`): Purple
- **Areas** (`path:Areas`): Blue
- **Projects** (`path:Projects`): Green
- **Knowledge** (`path:Knowledge`): Amber
- **Work** (`path:Work`): Red / Orange
