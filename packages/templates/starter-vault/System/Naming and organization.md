# Naming and organization

[[Home|Home]]

### Filename Rules
1. Use concise, human-readable sentence-case filenames with spaces (3 to 8 words, <= 70 chars).
2. The note filename stem and its primary `# H1 Heading` must agree.
3. Date prefix (`YYYY-MM-DD`) only for chronological session notes; never for evergreen concepts.
4. Never put raw hashes, UUIDs, or slugified URLs in visible filenames.
